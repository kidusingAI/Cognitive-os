# Cognitive Operating System (Cognitive-OS)

An advanced, 8-module multi-agent cognitive architecture designed to move AI from probabilistic guessing to verifiable, practical reasoning. 

Built as an asynchronous FastAPI web service, this system routes incoming prompts through a highly structured "System 2" thinking pipeline.

## The 8 Modules:
1. **Adaptive Router:** Triages tasks into Reflex, Analytical, or Heavy compute tiers.
2. **Truth Gate Ensemble:** A 5-agent decorrelated voting system requiring ≥70% consensus.
3. **Hegelian Red-Teaming:** A dialectic thesis/antithesis loop to falsify logic.
4. **Lemma Decomposer:** Breaks down logical impasses into solvable sub-goals.
5. **Concept DAG:** Tracks topological dependencies to prevent circular logic.
6. **Meta-Cognitive Detector:** Prunes search spaces and prevents endless loops.
7. **Utility Filter:** A hardcoded safety constitution and 80% real-world pragmatism threshold.
8. **Master Orchestrator:** The FastAPI endpoints that tie it all together.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Start the server: `python main.py`
3. Access the interactive API docs at `http://localhost:8000/docs`
